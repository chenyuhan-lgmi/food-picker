# 食刻 TASTE · 轻食点餐

依据用户提供的 11 张界面参考图实现的响应式点餐网站。暖米白与森林绿、统一的设计变量、自然光菜品摄影、iPad 横屏布局及手机适配。

## 本地预览

安装 Node.js 后，在本目录运行 `npm start`，访问 `http://127.0.0.1:4186`。网站为零外部运行依赖的静态 HTML、CSS、ES modules。

## 功能

首页、心情与状态筛选、分类浏览、关键词搜索、菜品详情、单品忌口、购物车、整单忌口、桌号确认、订单核对和演示提交均可操作。购物车及备注保存在当前浏览器本地。可通过 `?table=A08` 为扫码链接预设桌号。示例菜单按原始 XMind 的 16 道菜品与价格实现。

本网站是交互演示，尚未连接真实门店订单、服务员通知和支付。界面会明确说明演示反馈，提交不会扣款。

## 静态发布

`dist/` 是完整网站根目录，包含 `index.html`、`styles.css`、`data.js`、`app.js` 与 `assets/`。可直接托管这些文件；无需服务器端程序。本次发布至 `chenyuhan-lgmi/food-picker` 公开仓库的 `taste/` 子目录，使用该仓库现有的 GitHub Pages 托管。

## 视觉素材

首页及部分菜品照片从用户提供的界面参考图中提取。吐司、泰式牛肉沙拉、烤薯角、酸奶莓果杯、燕麦拿铁、多多卷、帕尼尼由内置 ImageGen 生成，均已保存至 `dist/assets/`。各菜品使用独立图片，未引用外部图片链接。生成提示词记录在 `ASSET-PROMPTS.md`。

`styles.css` 的 `:root` 定义颜色、字体、圆角、阴影和过渡变量；全站复用。手机布局在 640px 以下重排，iPad 分屏和平板在 900/1190px 断点调整。
